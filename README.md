# Look Again: Storm Studio Week 16

Interactive lesson week for the grades 9-12 EL block (Emerging + Progressing), Nov 30 - Dec 4, 2026. One 90-minute lesson per day, all in a single file (`index.html`).

| Day | Lesson | Language focus |
|---|---|---|
| Monday | Broccoli on Trial | Claim and evidence |
| Tuesday | The Climate Plate | Averages and qualifiers |
| Wednesday | The Mushroom Files | Fact, folklore, or label |
| Thursday | Ten Minutes Later | Sequence, cause and effect |
| Friday | The C That Was Not the End | Autobiography and turning points |

Each day runs the same nine steps: Opinion Line, Vocabulary Password, reading with claim/evidence marking, questions 1-8, Evidence Auction, listening with questions 9-12, Data Detective, 60-Second Pitch, writing and exit ticket.

Teacher view (agenda, keys, transcripts, rubric) opens by typing the word `teacher`.

Student work is saved on the device only. Students hand it in with "Copy my work" on the Wrap-up step.

Readings are original teaching texts, not transcriptions of their sources. Committee conversations and survey data are fictional unless a step says otherwise.

To publish: Settings -> Pages -> Deploy from branch -> main, root. The page will be at https://radan55.github.io/stormweek16/
